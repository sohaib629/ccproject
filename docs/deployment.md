# Deployment on DigitalOcean (DOKS)

Live URL: **https://stocksync.online**

## Architecture

```
Browser ──HTTPS──► stocksync.online (DigitalOcean DNS, A record)
                   │
                   ▼
        DigitalOcean Network Load Balancer "stocksync-lb"   (created by the Gateway)
                   │  TCP pass-through
                   ▼
        Gateway "stocksync" (DOKS managed Gateway API, Cilium/Envoy)
          :80   ACME HTTP-01 challenge, otherwise 301 → https
          :443  TLS terminated with Let's Encrypt certificate (cert-manager)
                   │
         ┌─────────┴──────────┐
     /api/*                  /*
  Service api:3000     Service frontend:8080
  (2–5 pods, HPA)        (2 nginx pods)
         │
  Service postgres (headless) → StatefulSet postgres-0
                                 └── PVC data-postgres-0 (do-block-storage = DigitalOcean Volume)
```

| Component | DigitalOcean resource |
|---|---|
| Cluster | DOKS `stocksync`, region `nyc3` (tor1 had no capacity for s-2vcpu-4gb on Nov 10, 2026), 2 × `s-2vcpu-4gb` nodes, **VPC-native** (required for the managed Gateway API) |
| Images | Container Registry (Basic tier: 5 repositories), images tagged with the git commit, built for `linux/amd64` |
| Ingress | Gateway API (`gatewayClassName: cilium`) → automatically provisioned Network Load Balancer |
| TLS | cert-manager v1.21 + Let's Encrypt (HTTP-01 through the Gateway); auto-renewal |
| Storage | PVC → DigitalOcean Volume (`do-block-storage`, default storage class) |
| DNS | DigitalOcean DNS for `stocksync.online` (nameservers delegated from Namecheap) |
| Monitoring | Resource alerts on all worker nodes (CPU, memory, disk) by tag `k8s:<cluster-id>`; external uptime check on `/api/health` with down and TLS-expiry alerts (`monitoring/setup-alerts.sh`) |
| Backups | Spaces bucket `stocksync-backups` (nyc3): nightly `pg_dump`, newest 7 kept, bucket-scoped key ([operations.md](operations.md)) |
| Deployment | GitHub Actions CD on every merge to `main` ([operations.md](operations.md)) |

The same base manifests run on minikube and DOKS. The `doks` overlay adds the
Gateway, routes and Certificate, the backup CronJobs, the registry pull Secret
and `DEPLOY_ENV=doks`.
`k8s/deploy.sh doks <tag>` pins the image versions and waits for every rollout.

## Design decisions

- **Gateway API instead of an Ingress controller.** The community Ingress NGINX
  project was retired in March 2026; DOKS ships a managed Gateway API (Cilium) at
  no extra cost. `/api` is routed straight to the API Service, so API calls do not
  pass through nginx.
- **TLS at the Gateway with cert-manager** rather than at the load balancer: the
  certificate lifecycle is declared in git (`Certificate`, `ClusterIssuer`) and
  works the same on any cluster. The load balancer passes TCP through.
- **HTTP → HTTPS redirect** on port 80, except the ACME challenge path, which
  cert-manager serves through a temporary, more specific HTTPRoute.
- **Images pinned to the git commit**, never `latest`, so every deployment is
  traceable and `kubectl rollout undo` returns to a known build.
- **Private registry pull Secret** (`docr`) generated by `doctl` at bootstrap; no
  registry credentials in git.

## Known limitations

- **Single database replica**: PostgreSQL is a single point of failure (the API is
  highly available, the database is not). Nightly backups to Spaces (see
  [operations.md](operations.md)) limit a loss to at most about a day of changes.
- **Client IP behind the load balancer**: the Network Load Balancer does not pass
  the browser's IP to the Gateway, so the login rate limit counts attempts per
  load-balancer/Gateway source rather than per user. Acceptable at this scale;
  PROXY protocol or an HTTP (regional) load balancer would fix it.
- **Cost while running**: about US$2/day (2 nodes, load balancer, registry, 1 GiB
  volume). Delete the cluster, load balancer and volume when the project is graded.

## Teardown (after grading)

```bash
doctl kubernetes cluster delete stocksync --dangerous   # also deletes LB and volumes it created
doctl registry delete <registry-name>
doctl compute domain delete stocksync.online
doctl monitoring uptime list      # then: doctl monitoring uptime delete <id>
doctl monitoring alert list       # then: doctl monitoring alert delete <uuid>
# Spaces: delete the bucket stocksync-backups and its access key in the
# control panel (Spaces Object Storage); then cancel the Spaces subscription.
# GitHub: delete the DigitalOcean token (API page) and the "production" environment.
```
